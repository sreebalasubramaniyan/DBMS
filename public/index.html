Aggregation Pipeline 1: Revenue & Order Performance by Restaurant

Calculates total revenue, order count, and average order value per restaurant using $match, $group, $lookup, and $project.

Order.aggregate([ { $match: { status: { $ne: 'Cancelled' } } }, { $group: { _id: '$restaurantId', totalRevenue: { $sum: '$totalAmount' }, orderCount: { $sum: 1 }, avgOrderValue: { $avg: '$totalAmount' } } }, { $lookup: { from: 'restaurants', localField: '_id', foreignField: '_id', as: 'restaurant' } }, { $unwind: '$restaurant' }, { $project: { restaurantName: '$restaurant.name', cuisine: '$restaurant.cuisine', totalRevenue: 1, orderCount: 1, avgOrderValue: { $round: ['$avgOrderValue', 2] } } }, { $sort: { totalRevenue: -1 } } ]);

Aggregation Pipeline 2: Top 5 Best-Selling Dishes ($unwind Array)

Unwinds the embedded orders.items[] array to aggregate sales volume and total revenue generated per dish.

Order.aggregate([ { $match: { status: { $ne: 'Cancelled' } } }, { $unwind: '$items' }, { $group: { _id: '$items.name', totalQuantitySold: { $sum: '$items.quantity' }, totalRevenue: { $sum: { $multiply: ['$items.price', '$items.quantity'] } } } }, { $project: { itemName: '$_id', totalQuantitySold: 1, totalRevenue: 1 } }, { $sort: { totalQuantitySold: -1 } }, { $limit: 5 } ]);
Rank Dish Name Units Sold Total Revenue Generated

Pipeline 3: Order Status Breakdown

Groups all customer orders by delivery status.

Order.aggregate([ { $group: { _id: '$status', count: { $sum: 1 } } }, { $project: { status: '$_id', count: 1, _id: 0 } }, { $sort: { count: -1 } } ]);
Status Order Count

Pipeline 4: Average Ratings & Reviews

Computes average customer rating from the reviews collection.

Review.aggregate([ { $group: { _id: '$restaurantId', averageRating: { $avg: '$rating' }, reviewCount: { $sum: 1 } } }, { $lookup: { from: 'restaurants', localField: '_id', foreignField: '_id', as: 'restaurant' } }, { $unwind: '$restaurant' }, { $project: { restaurantName: '$restaurant.name', averageRating: { $round: ['$averageRating', 2] }, reviewCount: 1 } }, { $sort: { averageRating: -1 } } ]);

Advanced NoSQL Feature: Database Indexing Strategy

Optimized indexes created on collections for high performance querying.

Collection Index Keys Index Type Optimization Purpose
restaurants { name: "text", cuisine: "text", location: "text" } Text Index Instant multi-attribute search across restaurant name, food type, and location.
menuItems { restaurantId: 1, categoryId: 1, isAvailable: 1 } Compound Index Fast retrieval and filtering of dishes by restaurant and category.
orders { userId: 1, orderDate: -1 } Compound Index Immediate sorting and rendering of customer order history.
reviews { restaurantId: 1, createdAt: -1 } Compound Index Fast lookup of restaurant reviews for live aggregation calculation.
