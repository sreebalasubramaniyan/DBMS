Criterion 3: Advanced NoSQL Feature 1 (5 Marks)

Multi-Stage Aggregation: Revenue by Restaurant

Aggregation Pipeline: Groups orders by restaurantId, joins restaurant metadata, and calculates total revenue, order count, and average order value.

Order.aggregate([ { $match: { status: { $ne: 'Cancelled' } } }, { $group: { _id: '$restaurantId', totalRevenue: { $sum: '$totalAmount' }, orderCount: { $sum: 1 }, avgOrderValue: { $avg: '$totalAmount' } } }, { $lookup: { from: 'restaurants', localField: '_id', foreignField: '_id', as: 'restaurant' } }, { $unwind: '$restaurant' }, { $project: { restaurantName: '$restaurant.name', cuisine: '$restaurant.cuisine', totalRevenue: 1, orderCount: 1, avgOrderValue: { $round: ['$avgOrderValue', 2] } } }, { $sort: { totalRevenue: -1 } } ]);

Criterion 3: Advanced NoSQL Feature 2 (5 Marks)

Array Unwinding Aggregation: Top 5 Best-Selling Dishes

Aggregation Pipeline ($unwind): Deconstructs the embedded orders.items[] array to aggregate sales volume and total revenue generated per dish.

Order.aggregate([ { $match: { status: { $ne: 'Cancelled' } } }, { $unwind: '$items' }, { $group: { _id: '$items.name', totalQuantitySold: { $sum: '$items.quantity' }, totalRevenue: { $sum: { $multiply: ['$items.price', '$items.quantity'] } } } }, { $project: { itemName: '$_id', totalQuantitySold: 1, totalRevenue: 1 } }, { $sort: { totalQuantitySold: -1 } }, { $limit: 5 } ]);

Criterion 3: Advanced NoSQL Feature 3 (5 Marks)

Database Indexing Strategy & Query Optimization

Explicit Text and Compound Indexes created to prevent collection scans (COLLSCAN) and ensure high-speed queries:

Target Collection Index Keys Specification Index Type Query Optimization Justification
restaurants { name: "text", cuisine: "text", location: "text" } Text Index Enables lightning-fast multi-keyword search across restaurant names, food types, and addresses.
menuItems { restaurantId: 1, categoryId: 1, isAvailable: 1 } Compound Accelerates combined filtering of menu items by restaurant and category without table scan.
orders { userId: 1, orderDate: -1 } Compound Enables instant retrieval and reverse chronological sorting of user order histories.
reviews { restaurantId: 1, createdAt: -1 } Compound Speeds up aggregation queries for calculating live restaurant ratings.
